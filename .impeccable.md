## Design Context

### Users
Uso personal, orientado a gestionar contactos y postulaciones para enviar CV y hacer seguimiento sin depender de Excel. En el futuro podria derivar en una app o servicio para terceros, pero hoy la prioridad es velocidad operativa individual.

### Brand Personality
Profesional, con detalles, confiable. La interfaz debe transmitir control, criterio y prolijidad sin verse rigida ni pesada.

### Aesthetic Direction
Aplicacion operativa de escritorio en modo claro, con tono ejecutivo y utilitario. La experiencia debe favorecer escaneo rapido, decision inmediata y bajo esfuerzo cognitivo. Debe evitar looks genericos de dashboard y tambien evitar exceso de decoracion.

### Design Principles
1. Priorizar lectura y accion por encima de adornos.
2. Hacer visible el siguiente paso con jerarquia clara.
3. Usar detalles refinados para transmitir confianza, no para distraer.
4. Mantener densidad util y consistente para trabajo repetitivo.
5. Diseñar para velocidad: menos ruido, menos pasos, mejor foco.
